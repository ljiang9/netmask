# netmask

子网计算器：CIDR 进，网络地址 / 广播 / 可用主机范围出。纯标准库，本地运行。

## 安装

零依赖，Python 3.10+：

```bash
cd netmask
python -m netmask 192.168.1.10/24
```

## 用法

```bash
# 基本信息
python -m netmask 192.168.1.10/24

# 判断 IP 是否属于该子网
python -m netmask 192.168.1.10/24 --contains 192.168.1.200

# 划分子网
python -m netmask 192.168.1.0/24 --split 26

# IPv6
python -m netmask 2001:db8::/32

# JSON 输出
python -m netmask 10.0.0.0/8 --json
```

输出示例：

```

首个可用主机：192.168.1.1
末个可用主机：192.168.1.254
可用主机数：254
地址总数：256
私有地址：是
公网地址：否
```

## IPv6 说明

IPv6 没有广播地址的概念（用组播替代），且"可用主机"的说法不适用，
因此 IPv6 只显示：网络地址、前缀长度、掩码、地址总数、私有/公网属性。
`--split` 和 `--contains` 对 IPv6 同样可用。

## 已知局限

- 可用主机数按"减去网络地址和广播地址"计算（/31 按 RFC 3021 算 2 个可用，/32 算 1 个）；
- 私有/公网判断依据 `ipaddress` 内置规则（含文档/testnet 等特殊段）；
- 不做 WHOIS / 归属地查询，只做纯数学计算。
- 本工具只做计算，不修改任何网络配置。
